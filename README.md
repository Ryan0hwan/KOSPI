# 한국 주식 스캐너 (5종) + 수급 체크 + 시장 수급

미국 주식용으로 만든 스캐너 5개를 **코스피·코스닥** 대상으로 똑같이 돌립니다. 판정 조건은 미국판과 같고, 종목 목록·시세·가격 단위(원)만 한국에 맞췄습니다.

| 파일 | 시스템 | 미국판 |
|---|---|---|
| `kr_ma.py` | 이평선 지지 (50일·100일 VWMA·200일 + ⭐확률높은종목 + 📉장기 지지선) | ma-scanner |
| `kr_trend.py` | 미너비니 트렌드 템플릿 (8조건·신규 진입·20/30/50일선 눌림) | trend-scanner |
| `kr_vcp.py` | 미너비니 VCP 검색기 (7조건·돌파·피벗 근접·형성 중·진단) | vcp-scanner |
| `kr_triangle.py` | 업센딩 트라이앵글 (일봉·주봉, 진단) | triangle-scanner |
| `kr_bb.py` | 볼린저밴드 과매도 반등 (반등 확인·반등 대기) | bb-scanner |
| `kr_flow.py` | 💰 **수급 체크** (내가 고른 종목의 외국인·기관·개인 수급) | — (한국 전용) |
| `kr_marketflow.py` | 🏦 **시장 수급** (코스피·코스닥 전체 + 동반 매수·수급 주도주·상위/하위) | — (한국 전용) |
| `krcommon.py` | 한국 종목 목록·시세·종목명 (공통) | — |

## 스캔 대상

| 항목 | 기준 |
|---|---|
| 종목 목록 | 코스피·코스닥 보통주 중 **시가총액 1조 원 이상 + 최근 20거래일 평균 거래대금 100억 원 이상** (약 200종목: 코스피 약 140, 코스닥 약 60) |
| 제외 | 우선주, 스팩, 관리종목, 투자주의환기종목, 코넥스 |
| 추가 | `kr_watchlist.txt`에 적은 종목은 시가총액·거래대금과 상관없이 항상 포함 |
| 왜 좁혔나 | 한국장은 수급(외국인·기관)이 지배하고 소형주는 테마·작전성 급등락이 많아 이평선·패턴 매매가 잘 안 통함. 외국인·기관이 실제로 매매하는 대형·중형주만 남김 |
| 각 시스템 공통 | 주가 1,000원 이상, 50일 평균 거래대금 20억 원 이상 |
| 상대강도(RS) | 스캔 대상 종목 안에서의 순위. 이평선 스캐너의 "시장보다 강함" 비교 기준은 **코스피 지수** |

종목 목록은 KRX 일별 시세(FinanceDataReader가 GitHub에 매일 올리는 KRX 데이터)로 만들고, 시세는 야후 파이낸스(코스피 `.KS`, 코스닥 `.KQ`)에서 받습니다.

## 💰 수급 체크 (`kr_flow.py`)

`flow_list.txt`에 적은 종목(주식·ETF)의 투자자별 순매수를 **평일 아침 08:00**에 보냅니다 (전날 확정 수급, 월요일에는 금요일 수급). 별도 워크플로(`.github/workflows/flow.yml`)로 돌아갑니다.

| 항목 | 내용 |
|---|---|
| 데이터 | 네이버 증권 (모바일 API로 외국인·기관·개인, 실패하면 PC 페이지로 외국인·기관) |
| 전일 | 직전 거래일 순매수 (억 원 = 수량 × 종가) |
| 1주 · 2주 | 최근 5거래일 · 10거래일 누적 |
| 연속 | 오늘까지 같은 방향이 이어진 거래일 수 (`+4d` = 4일 연속 순매수) |
| 판정 (1주 기준) | 🟢 외국인·기관 동반 순매수 · 🔵 외국인 주도 · 🟣 기관 주도 · 🔴 동반 순매도 |
| 흐름 메모 | 매도→매수 전환, 매수 가속(최근 1주가 그 전 1주의 1.5배 이상), 3일 이상 연속, 주가와 수급이 엇갈림, 인버스·레버리지 ETF의 개인 베팅, 외국인 보유율 변화 |

```
💰 수급 체크 | 10/29(목) 기준
[매일 체크 종목]
🔵 외   +626 기    -54 개   -571  삼성전자
🟣 외   -136 기    +75 개    +61  SK하이닉스

📋 매일 체크 종목
삼성전자 005930  종가 244,000 (+9.9%)
          전일     1주     2주   연속
외국인     +83    +626    +910    +7d
기관       -32     -54    +131    -1d
개인       -51    -571  -1,041    -7d
→ 🔵 외국인 주도 매수 (1주) · 거래대금 대비 +6%
  · 외국인 7일 연속 순매수
```

**종목 바꾸기**: `flow_list.txt`에 종목코드를 한 줄에 하나씩 적습니다. `# ── 이름 ──` 줄로 묶음을 나눌 수 있습니다.

**설치 추가분**: 디스코드 채널 하나(예: `kr-수급`)를 더 만들고, 웹후크를 Secret `KR_WEBHOOK_FLOW`로 등록하면 됩니다. 테스트는 **Actions → KR Flow → Run workflow**.

⚠️ ETF의 기관 수급에는 유동성공급자(LP, 증권사)가 호가를 내는 물량이 섞여 있어서, 주식보다 의미가 약합니다. ETF는 외국인·개인 흐름 위주로 보세요.

## 🏦 시장 수급 (`kr_marketflow.py`)

**평일 18:30**에 국장 전체 수급을 보냅니다 (확정 수급 반영 후). 별도 워크플로(`.github/workflows/marketflow.yml`)로 돌아갑니다.

| 섹션 | 내용 |
|---|---|
| 🏦 시장 수급 | 코스피·코스닥 투자자별 순매수 (당일·5일·20일, 억 원) + **기관 세부** (금융투자·투신·연기금·보험·은행) + 연속 일수 + 해석 |
| 🏭 업종별 수급 | 약 200종목을 **약 28개 업종**(반도체, 반도체 장비/소재, 2차전지, 조선, 방산/우주, 전력기기/전선, 바이오/제약, 은행, 증권, 지주사 등)으로 묶어 외국인·기관 1주·20일 순매수 합계. 🟢 동반 유입 · 🔴 동반 이탈 · 유입 상위 3 · 이탈 상위 3 · **유입 전환**(20일 순매도인데 1주 순매수)·**이탈 전환** |
| 🤝 동반 순매수 | 스캔 대상(시총 1조+·거래대금 100억+ 약 200종목 + 관심종목) 중 외국인·기관이 1주 동안 함께 산 종목 상위 15 |
| 🚀 수급 주도주 | 동반 순매수 + **50일선 위 + 52주 고점 −10% 이내** (★ = 50일선 > 200일선). 상위 20 |
| 🔵🟣 TOP 10 | 외국인·기관 각각 1주 순매수 상위 10 |
| 🔻 TOP 10 | 외국인·기관 각각 1주 순매도 상위 10 |

```

외국인         -2,648   -2,534     -735    -2d
```

업종 분류는 KRX 상장사 정보(세부업종·주요제품)를 규칙으로 묶은 것이라, 일부 종목은 실제 사업과 다르게 묶일 수 있습니다. 잘못 묶인 종목은 `kr_marketflow.py`의 `OVERRIDE_NAME`에 `"종목명": "업종"`으로 추가하면 됩니다.

**설치 추가분**: 디스코드 채널(예: `kr-시장수급`)을 만들고 웹후크를 Secret `KR_WEBHOOK_MARKET`으로 등록. **Add file → Create new file**로 `.github/workflows/marketflow.yml` 생성. 테스트는 **Actions → KR Market Flow → Run workflow** (약 3~5분, 종목 200개를 하나씩 받기 때문).

## 설치 (약 15분, 저장소는 1개)

### 1. 디스코드 채널 7개와 웹후크
시스템마다 채널을 하나씩 만들고(예: `kr-이평선`, `kr-미너비니`, `kr-vcp`, `kr-삼각형`, `kr-볼린저`, `kr-수급`, `kr-시장수급`), 각 채널에서 **⚙ → 연동 → 웹후크 → 새 웹후크 → 웹후크 URL 복사**. 7개 주소를 메모장에 적어 두세요.

### 2. GitHub 새 저장소
github.com 오른쪽 위 `+` → New repository → 이름 `kr-scanners` → Public → Create repository
→ **uploading an existing file** → `krcommon.py`, `kr_ma.py`, `kr_trend.py`, `kr_vcp.py`, `kr_triangle.py`, `kr_bb.py`, `kr_flow.py`, `kr_marketflow.py`, `kr_watchlist.txt`, `flow_list.txt`, `requirements.txt`, `README.md` (12개) 끌어다 놓기 → Commit changes

### 3. 자동 실행 파일
**Add file → Create new file** → 이름 칸에 `.github/workflows/main.yml` → zip 안의 같은 파일을 메모장으로 열어 전체 복사·붙여넣기 → Commit changes. 같은 방법으로 `.github/workflows/flow.yml`과 `.github/workflows/marketflow.yml`도 만듭니다.

### 4. 웹후크 5개 등록
**Settings → Secrets and variables → Actions → New repository secret**을 7번 반복합니다. 이름은 대문자 그대로 입력하세요.

| Name | Secret |
|---|---|
| `KR_WEBHOOK_MA` | 이평선 채널 웹후크 |
| `KR_WEBHOOK_TREND` | 미너비니(트렌드) 채널 웹후크 |
| `KR_WEBHOOK_VCP` | VCP 채널 웹후크 |
| `KR_WEBHOOK_TRIANGLE` | 삼각형 채널 웹후크 |
| `KR_WEBHOOK_BB` | 볼린저 채널 웹후크 |
| `KR_WEBHOOK_FLOW` | 수급 체크 채널 웹후크 |
| `KR_WEBHOOK_MARKET` | 시장 수급 채널 웹후크 |

등록하지 않은 시스템은 실행은 되지만 디스코드로 보내지 않습니다.

### 5. 테스트
**Actions → KR Scanners → Run workflow** → system `all` → 초록 버튼. 첫 단계(universe)에서 종목 목록을 만들고, 이어서 5개 시스템이 동시에 돌아갑니다 (5~15분).

전체 실행 버튼(run-all)을 설치해 두셨다면 이 저장소도 자동으로 포함됩니다.

## 수동 실행 옵션

| 입력 | 설명 |
|---|---|
| system | `all` 또는 하나만 (`ma`, `trend`, `vcp`, `triangle`, `bb`) |
| force | 켜 두면 휴장일·장 시간과 상관없이 가장 최근 거래일 기준으로 실행 |
| diagnose | VCP·삼각형 진단. 종목코드나 종목명을 쉼표로 (`005930,에이피알`). VCP는 날짜 지정 가능 (`005930@2026-01-05`). 진단만 보려면 system을 `vcp`나 `triangle`로 고르세요 |

## 설정 바꾸기

공통 기준은 `.github/workflows/main.yml`의 `env:` 부분에서 바꿉니다.

| 항목 | 현재값 | 의미 |
|---|---|---|
| `MIN_MARCAP` | 1000000000000 | 종목 목록: 시가총액 하한(원) — 1조 |
| `MIN_TURNOVER` | 10000000000 | 종목 목록: 20일 평균 거래대금 하한(원) — 100억 |
| `MIN_PRICE` | 1000 | 최소 주가(원) |
| `MIN_DOLLAR_VOL` | 2000000000 | 각 시스템: 50일 평균 거래대금 하한(원) |

시스템별 세부 조건(VCP 수축 기준, 볼린저 %B 등)은 각 `kr_*.py` 파일 맨 위 설정 부분에서 바꾸며, 이름과 의미는 미국판 README와 같습니다.

## 알아둘 점

- 한국 시장은 상·하한가(±30%)와 테마 급등락이 많아서, 같은 조건이라도 미국보다 신호가 거칠게 나올 수 있습니다. 처음 1~2주는 결과를 보면서 기준을 맞춰 가는 것을 추천합니다.
- 상장한 지 1년이 안 된 종목은 200일선·52주 계산이 안 돼서 미너비니·이평선 조건에서 빠집니다.
- 신규 상장 종목의 새 형식 코드(예: `0126Z0`)는 야후에 시세가 없을 수 있습니다. 그런 종목은 조용히 건너뜁니다.
