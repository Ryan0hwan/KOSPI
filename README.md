# 한국 주식 스캐너 (5종)

미국 주식용으로 만든 스캐너 5개를 **코스피·코스닥** 대상으로 똑같이 돌립니다. 판정 조건은 미국판과 같고, 종목 목록·시세·가격 단위(원)만 한국에 맞췄습니다.

| 파일 | 시스템 | 미국판 |
|---|---|---|
| `kr_ma.py` | 이평선 지지 (50일·100일 VWMA·200일 + ⭐확률높은종목 + 📉장기 지지선) | ma-scanner |
| `kr_trend.py` | 미너비니 트렌드 템플릿 (8조건·신규 진입·20/30/50일선 눌림) | trend-scanner |
| `kr_vcp.py` | 미너비니 VCP 검색기 (7조건·돌파·피벗 근접·형성 중·진단) | vcp-scanner |
| `kr_triangle.py` | 업센딩 트라이앵글 (일봉·주봉, 진단) | triangle-scanner |
| `kr_bb.py` | 볼린저밴드 과매도 반등 (반등 확인·반등 대기) | bb-scanner |
| `krcommon.py` | 한국 종목 목록·시세·종목명 (공통) | — |

## 스캔 대상

| 항목 | 기준 |
|---|---|
| 종목 목록 | 코스피·코스닥 보통주 중 **최근 20거래일 평균 거래대금 30억 원 이상** (약 500~650종목) |
| 제외 | 우선주, 스팩, 관리종목, 투자주의환기종목, 코넥스 |
| 추가 | `kr_watchlist.txt`에 적은 종목은 거래대금과 상관없이 항상 포함 |
| 각 시스템 공통 | 주가 1,000원 이상, 50일 평균 거래대금 20억 원 이상 |
| 상대강도(RS) | 스캔 대상 종목 안에서의 순위. 이평선 스캐너의 "시장보다 강함" 비교 기준은 **코스피 지수** |

종목 목록은 KRX 일별 시세(FinanceDataReader가 GitHub에 매일 올리는 KRX 데이터)로 만들고, 시세는 야후 파이낸스(코스피 `.KS`, 코스닥 `.KQ`)에서 받습니다.

## 실행 시각 (평일, 한국 시각)

| 시각 | 실행 |
|---|---|
| 10:30 · 13:00 | 이평선만 (장중 터치) |
| 15:00 | 이평선 + 📉 장기 지지선 |
| **16:10** | **5개 전부** (장 마감 후 확정 데이터) |

GitHub 사정으로 5~30분 늦을 수 있습니다. 야후 한국 시세는 약 20분 지연입니다. 휴장일에는 시세가 없어 자동으로 건너뜁니다.

## 설치 (약 15분, 저장소는 1개)

### 1. 디스코드 채널 5개와 웹후크
시스템마다 채널을 하나씩 만들고(예: `kr-이평선`, `kr-미너비니`, `kr-vcp`, `kr-삼각형`, `kr-볼린저`), 각 채널에서 **⚙ → 연동 → 웹후크 → 새 웹후크 → 웹후크 URL 복사**. 5개 주소를 메모장에 적어 두세요.

### 2. GitHub 새 저장소
github.com 오른쪽 위 `+` → New repository → 이름 `kr-scanners` → Public → Create repository
→ **uploading an existing file** → `krcommon.py`, `kr_ma.py`, `kr_trend.py`, `kr_vcp.py`, `kr_triangle.py`, `kr_bb.py`, `kr_watchlist.txt`, `requirements.txt`, `README.md` (9개) 끌어다 놓기 → Commit changes

### 3. 자동 실행 파일
**Add file → Create new file** → 이름 칸에 `.github/workflows/main.yml` → zip 안의 같은 파일을 메모장으로 열어 전체 복사·붙여넣기 → Commit changes

### 4. 웹후크 5개 등록
**Settings → Secrets and variables → Actions → New repository secret**을 5번 반복합니다. 이름은 대문자 그대로 입력하세요.

| Name | Secret |
|---|---|
| `KR_WEBHOOK_MA` | 이평선 채널 웹후크 |
| `KR_WEBHOOK_TREND` | 미너비니(트렌드) 채널 웹후크 |
| `KR_WEBHOOK_VCP` | VCP 채널 웹후크 |
| `KR_WEBHOOK_TRIANGLE` | 삼각형 채널 웹후크 |
| `KR_WEBHOOK_BB` | 볼린저 채널 웹후크 |

등록하지 않은 시스템은 실행은 되지만 디스코드로 보내지 않습니다.

### 5. 테스트
**Actions → KR Scanners → Run workflow** → system `all` → 초록 버튼. 첫 단계(universe)에서 종목 목록을 만들고, 이어서 5개 시스템이 동시에 돌아갑니다 (5~15분).

전체 실행 버튼(run-all)을 설치해 두셨다면 이 저장소도 자동으로 포함됩니다.

## 수동 실행 옵션

| 입력 | 설명 |
|---|---|
| system | `all` 또는 하나만 (`ma`, `trend`, `vcp`, `triangle`, `bb`) |
| force | 켜 두면 휴장일·장 시간과 상관없이 가장 최근 거래일 기준으로 실행 |
| diagnose | VCP·삼각형 진단. 종목코드나 종목명을 쉼표로 (`005930,에이피알`). VCP는 날짜 지정 가능 (`005930@2026-01-05`). 진단만 보려면 system을 `vcp`나 `triangle`로 고르세요 |

## 관심종목 추가

`kr_watchlist.txt`에 종목코드나 종목명을 한 줄에 하나씩 적으면 됩니다.

```
005930
에이피알
247540, 에코프로비엠
```

## 설정 바꾸기

공통 기준은 `.github/workflows/main.yml`의 `env:` 부분에서 바꿉니다.

| 항목 | 현재값 | 의미 |
|---|---|---|
| `MIN_TURNOVER` | 3000000000 | 종목 목록: 20일 평균 거래대금 하한(원) |
| `MIN_PRICE` | 1000 | 최소 주가(원) |
| `MIN_DOLLAR_VOL` | 2000000000 | 각 시스템: 50일 평균 거래대금 하한(원) |

시스템별 세부 조건(VCP 수축 기준, 볼린저 %B 등)은 각 `kr_*.py` 파일 맨 위 설정 부분에서 바꾸며, 이름과 의미는 미국판 README와 같습니다.

## 알아둘 점

- 한국 시장은 상·하한가(±30%)와 테마 급등락이 많아서, 같은 조건이라도 미국보다 신호가 거칠게 나올 수 있습니다. 처음 1~2주는 결과를 보면서 기준을 맞춰 가는 것을 추천합니다.
- 상장한 지 1년이 안 된 종목은 200일선·52주 계산이 안 돼서 미너비니·이평선 조건에서 빠집니다.
- 신규 상장 종목의 새 형식 코드(예: `0126Z0`)는 야후에 시세가 없을 수 있습니다. 그런 종목은 조용히 건너뜁니다.
